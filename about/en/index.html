SECTION / 01

Sometimes, an idea simply appears.

"This could be interesting."
That's where it begins.

First, figure out whether it can be done.
If you don't know how, learn.
If there is no existing method, find one.
And when necessary, try something completely different.

Instead of asking whether something can be done,
ask how it can be done.

Not knowing something is never a reason to stop.

SECTION / 02

If it doesn't exist, build it.

There is no fixed form to what KURENAI creates.

Prompts.
Training sets.
AI systems.
Applications.
Websites.
Visuals.

Things that seem interesting.
Things that seem necessary.
Things that simply need to exist.

Whatever it is, build it.

SECTION / 03

And once the decision is made to do it,
see it through to the end unless it is physically impossible.

What "finished" means depends on what is being made.

But when something is created for other people to use,
usability comes first.

There is no guarantee that everything can be made perfect.
That is exactly why the goal is to find the best possible solution
with what is available at that moment.

How others judge it is up to them.
