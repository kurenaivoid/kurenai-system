02 / QUICK START

操作ガイド

画面内の各コントロール名は、公開中のツール本体の表示に合わせて確認してください。

Web版を開く

「Launch Web System」を押してツールを起動。表示が整うまで少し待ちます。

テキストを入力

テキスト欄に表示したい文字列を入力し、表示モードを選択します。文字変換が必要な場合は、変換結果も確認してください。

画面を調整

切替速度・文字サイズ・演出・画像位置や倍率を調整し、目的の見え方に合わせます。

録画・保存

録画開始で画面を記録し、必要に応じて全画面表示を使用します。保存形式はブラウザの対応状況に依存します。
